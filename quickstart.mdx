This guide takes you from zero to a working terminal in the browser. You will install xterm.js, render a terminal on the page, and connect it to a backend process.

## Before you start

You need Node.js and npm installed. The rest runs in the browser with a bundler (Vite, webpack, esbuild) or as a plain HTML file.

## Steps

<Steps>
  <Step title="Install the package">
    Install `@xterm/xterm` from npm. Also install `@xterm/addon-fit` to automatically size the terminal to its container.

    <CodeGroup>

    ```bash npm
    npm install @xterm/xterm @xterm/addon-fit
    ```

    ```bash yarn
    yarn add @xterm/xterm @xterm/addon-fit
    ```

    ```bash pnpm
    pnpm add @xterm/xterm @xterm/addon-fit
    ```

    </CodeGroup>
  </Step>

  <Step title="Add a container element to your HTML">
    xterm.js mounts into any `div`. Give it an explicit height — the terminal will fill the container.

    ```html
    <div id="terminal" style="height: 400px;"></div>
    ```

    <Note>
      You must also include the xterm.js stylesheet. Without it, the terminal will not render correctly.

      ```html
      <link rel="stylesheet" href="node_modules/@xterm/xterm/css/xterm.css" />
      ```

      If you are using a bundler, import the CSS in your JavaScript entry point instead:

      ```typescript
      import '@xterm/xterm/css/xterm.css';
      ```
    </Note>
  </Step>

  <Step title="Create and open a Terminal instance">
    Import `Terminal`, create an instance, and call `open` with the container element.

    <Tabs>
      <Tab title="TypeScript">
        ```typescript
        import { Terminal } from '@xterm/xterm';
        import { FitAddon } from '@xterm/addon-fit';
        import '@xterm/xterm/css/xterm.css';

        const term = new Terminal();
        const fitAddon = new FitAddon();

        term.loadAddon(fitAddon);
        term.open(document.getElementById('terminal')!);
        fitAddon.fit();

        term.write('Hello from \x1B[1;3;31mxterm.js\x1B[0m $ ');
        ```
      </Tab>
      <Tab title="JavaScript">
        ```javascript
        import { Terminal } from '@xterm/xterm';
        import { FitAddon } from '@xterm/addon-fit';
        import '@xterm/xterm/css/xterm.css';

        const term = new Terminal();
        const fitAddon = new FitAddon();

        term.loadAddon(fitAddon);
        term.open(document.getElementById('terminal'));
        fitAddon.fit();

        term.write('Hello from \x1B[1;3;31mxterm.js\x1B[0m $ ');
        ```
      </Tab>
    </Tabs>

    `FitAddon.fit()` resizes the terminal to fill its container. Call it again whenever the container is resized (for example, inside a `ResizeObserver` or a window `resize` listener).
  </Step>

  <Step title="Connect to a backend process">
    xterm.js on its own only renders output and captures keystrokes. To run real commands, connect it to a pseudoterminal (PTY) on the server. The standard approach is [node-pty](https://github.com/microsoft/node-pty) on the server and a WebSocket in between.

    <Tabs>
      <Tab title="TypeScript">
        ```typescript
        // Client side — wire xterm.js to a WebSocket
        const socket = new WebSocket('ws://localhost:3000');

        // Data from the server (PTY output) → write to terminal
        socket.addEventListener('message', (event) => {
          term.write(event.data);
        });

        // User input from the terminal → send to server (PTY input)
        term.onData((data) => {
          socket.send(data);
        });
        ```
      </Tab>
      <Tab title="JavaScript">
        ```javascript
        // Client side — wire xterm.js to a WebSocket
        const socket = new WebSocket('ws://localhost:3000');

        // Data from the server (PTY output) → write to terminal
        socket.addEventListener('message', (event) => {
          term.write(event.data);
        });

        // User input from the terminal → send to server (PTY input)
        term.onData((data) => {
          socket.send(data);
        });
        ```
      </Tab>
    </Tabs>

    On the server, use node-pty to spawn a shell and bridge it to the WebSocket:

    ```javascript
    import * as pty from 'node-pty';
    import { WebSocketServer } from 'ws';

    const wss = new WebSocketServer({ port: 3000 });

    wss.on('connection', (ws) => {
      const ptyProcess = pty.spawn('bash', [], {
        name: 'xterm-color',
        cols: 80,
        rows: 24,
        env: process.env,
      });

      // PTY output → send to client
      ptyProcess.onData((data) => ws.send(data));

      // Client input → write to PTY
      ws.on('message', (data) => ptyProcess.write(data.toString()));

      ws.on('close', () => ptyProcess.kill());
    });
    ```

    <Tip>
      See the [Connecting a PTY](/guides/connecting-a-pty) guide for a complete working example including terminal resize handling.
    </Tip>
  </Step>
</Steps>

## Standalone HTML example

If you are not using a bundler, you can load xterm.js directly from the `node_modules` folder or a CDN. Here is a complete self-contained HTML file from the xterm.js README:

```html
<!doctype html>
<html>
  <head>
    <link rel="stylesheet" href="node_modules/@xterm/xterm/css/xterm.css" />
    <script src="node_modules/@xterm/xterm/lib/xterm.js"></script>
  </head>
  <body>
    <div id="terminal"></div>
    <script>
      const term = new Terminal();
      term.open(document.getElementById('terminal'));
      term.write('Hello from \x1B[1;3;31mxterm.js\x1B[0m $ ');
    </script>
  </body>
</html>
```
