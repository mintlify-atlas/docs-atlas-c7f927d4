xterm.js (`@xterm/xterm`) is a frontend library that lets you embed a fully-featured terminal emulator in any web application. It handles VT100/xterm escape sequences, mouse events, Unicode, and GPU-accelerated rendering — so you can focus on connecting it to your backend.

<Note>
  **xterm.js is not a terminal application you can download and run.** It is also not a shell like `bash` or `zsh`. It is a library that renders terminal output in the browser and captures user input. To run actual commands, you connect it to a process — typically via [node-pty](https://github.com/microsoft/node-pty) on the server side.
</Note>

## Who uses xterm.js

xterm.js is the terminal engine behind many widely used applications:

- **[VS Code](https://code.visualstudio.com/)** — the integrated terminal in Microsoft's editor and all its forks
- **[Hyper](https://hyper.is/)** — the web-technology-based terminal application
- **[Tabby](https://tabby.sh/)** — a highly configurable terminal emulator
- **[JupyterLab](https://github.com/jupyterlab/jupyterlab)** — the interactive computing environment for Jupyter notebooks
- **[Azure Cloud Shell](https://shell.azure.com)** — Microsoft's browser-based admin shell
- **[Replit](https://replit.com)** — the collaborative browser-based IDE
- **[Coder](https://github.com/coder/coder)** — self-hosted remote development environments
- **[Eclipse Che](https://www.eclipse.org/che)** — the cloud-native developer workspace server
- **[Proxmox VE](https://www.proxmox.com/en/proxmox-ve)** — enterprise virtualization platform container terminals
- **[Portainer](https://portainer.io)** — Docker management UI

[Many more projects](https://github.com/xtermjs/xterm.js/network/dependents?package_id=UGFja2FnZS0xNjYzMjc4OQ%3D%3D) use xterm.js across cloud IDEs, SSH clients, IoT dashboards, and CI platforms.

## The npm package

xterm.js is distributed exclusively through npm as `@xterm/xterm`. The current stable version is **6.0.0**.

```bash
npm install @xterm/xterm
```

Both ESM and CommonJS builds are included. TypeScript types are bundled at `typings/xterm.d.ts` and resolved automatically.
