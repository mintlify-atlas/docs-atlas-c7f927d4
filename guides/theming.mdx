xterm.js exposes a rich set of visual options through `ITerminalOptions`. Colors are controlled by the `theme` property (an `ITheme` object), while typography, cursor behavior, and scrollbar appearance each have their own dedicated options.

## The ITheme interface

The `theme` option accepts an `ITheme` object. Every property is optional—unset properties fall back to the built-in defaults.

| Property | Description |
|---|---|
| `foreground` | Default text color |
| `background` | Terminal background color |
| `cursor` | Cursor color |
| `cursorAccent` | Foreground color rendered inside a block cursor |
| `selectionBackground` | Selection highlight color (supports alpha) |
| `selectionForeground` | Text color within a selection |
| `selectionInactiveBackground` | Selection color when the terminal is not focused (supports alpha) |
| `scrollbarSliderBackground` | Scrollbar thumb color (defaults to `foreground` at 20% opacity) |
| `scrollbarSliderHoverBackground` | Scrollbar thumb on hover (defaults to `foreground` at 40% opacity) |
| `scrollbarSliderActiveBackground` | Scrollbar thumb while dragging (defaults to `foreground` at 50% opacity) |
| `overviewRulerBorder` | Border color between the terminal and the overview ruler |
| `black` … `brightWhite` | The 16 standard ANSI colors |
| `extendedAnsi` | Array of up to 240 additional colors for ANSI indices 16–255 |

<Note>
The `theme` option is an object reference. Mutating the existing object after assignment will not trigger a re-render. Always assign a new object when updating theme at runtime.
</Note>

## Setting theme at construction

Pass a `theme` object as part of the constructor options:

```typescript
import { Terminal } from '@xterm/xterm';

const terminal = new Terminal({
  theme: {
    background: '#1e1e1e',
    foreground: '#d4d4d4',
    cursor: '#aeafad',
    black: '#000000',
    red: '#cd3131',
    green: '#0dbc79',
    yellow: '#e5e510',
    blue: '#2472c8',
    magenta: '#bc3fbc',
    cyan: '#11a8cd',
    white: '#e5e5e5',
    brightBlack: '#666666',
    brightRed: '#f14c4c',
    brightGreen: '#23d18b',
    brightYellow: '#f5f543',
    brightBlue: '#3b8eea',
    brightMagenta: '#d670d6',
    brightCyan: '#29b8db',
    brightWhite: '#e5e5e5',
  },
});
```

## Updating theme at runtime

Assign a new object to `terminal.options.theme`. Spread the previous value to change only specific properties:

```typescript
// Switch to a light theme at runtime
terminal.options.theme = {
  ...terminal.options.theme,
  background: '#ffffff',
  foreground: '#333333',
  cursor: '#333333',
};
```

## Font options

Control the typeface and spacing with these options:

| Option | Type | Description |
|---|---|---|
| `fontFamily` | `string` | CSS font-family string. Use a monospace font. |
| `fontSize` | `number` | Font size in pixels. Default: `15`. |
| `fontWeight` | `FontWeight` | Weight for normal text. Accepts CSS weight values or `'normal'` / `'bold'`. |
| `fontWeightBold` | `FontWeight` | Weight for bold text. |
| `letterSpacing` | `number` | Extra spacing between characters in whole pixels. |
| `lineHeight` | `number` | Line height multiplier relative to font size. Default: `1`. |

```typescript
const terminal = new Terminal({
  fontFamily: '"Cascadia Code", "Fira Code", monospace',
  fontSize: 14,
  fontWeight: '400',
  fontWeightBold: '700',
  letterSpacing: 0,
  lineHeight: 1.2,
});
```

## Cursor options

| Option | Type | Description |
|---|---|---|
| `cursorStyle` | `'block' \| 'underline' \| 'bar'` | Shape of the cursor when the terminal is focused. |
| `cursorBlink` | `boolean` | Whether the cursor blinks. Stops after 5 minutes of idle time. |
| `cursorWidth` | `number` | Width in CSS pixels when `cursorStyle` is `'bar'`. |
| `cursorInactiveStyle` | `'outline' \| 'block' \| 'bar' \| 'underline' \| 'none'` | Cursor shape when the terminal is not focused. |

```typescript
const terminal = new Terminal({
  cursorStyle: 'bar',
  cursorBlink: true,
  cursorWidth: 2,
  cursorInactiveStyle: 'outline',
});
```

Update cursor options at runtime:

```typescript
terminal.options.cursorStyle = 'block';
terminal.options.cursorBlink = false;
```

## Scrollbar options

The `scrollbar` option accepts an `IScrollbarOptions` object:

| Property | Type | Description |
|---|---|---|
| `showScrollbar` | `boolean` | Whether to show the scrollbar. Supersedes `width` when `false`. Default: `true`. |
| `showArrows` | `boolean` | Show up/down arrows at the ends of the scrollbar. Default: `false`. |
| `width` | `number` | Width in CSS pixels. Also enables the overview ruler when set. |

```typescript
const terminal = new Terminal({
  scrollbar: {
    showScrollbar: true,
    showArrows: true,
    width: 14,
  },
});
```

Setting `scrollbar.width` enables the **overview ruler**, a minimap-style strip alongside the scrollbar that visualizes decorations such as search matches. The ruler border color is controlled by `theme.overviewRulerBorder`.

## Combining all options

```typescript
import { Terminal } from '@xterm/xterm';

const terminal = new Terminal({
  fontFamily: '"JetBrains Mono", monospace',
  fontSize: 14,
  lineHeight: 1.15,
  cursorStyle: 'bar',
  cursorBlink: true,
  cursorWidth: 2,
  cursorInactiveStyle: 'outline',
  scrollbar: {
    showScrollbar: true,
    width: 12,
  },
  theme: {
    background: '#1a1a2e',
    foreground: '#eaeaea',
    cursor: '#ffcc00',
    cursorAccent: '#1a1a2e',
    selectionBackground: 'rgba(255, 255, 255, 0.2)',
```
