Xterm.js is a frontend library that lets you embed a fully-featured terminal in any web application. It handles VT100/xterm escape sequences, mouse events, Unicode, and GPU-accelerated rendering — so you can focus on connecting it to your backend.

## Why xterm.js?

<CardGroup cols={2}>
  <Card title="Performant" icon="bolt">
    Built-in WebGL renderer delivers GPU-accelerated, frame-rate-smooth output even for heavy workloads like `cat`-ing large files or running `htop`.
  </Card>
  <Card title="Standards-compliant" icon="check">
    Full VT100/VT220/xterm escape sequence support including SGR colors, mouse reports, alternate buffer, and modern extensions like the kitty keyboard protocol.
  </Card>
  <Card title="Rich Unicode" icon="globe">
    CJK characters, emoji, IME composition, and grapheme cluster support — all handled correctly, including double-width glyphs.
  </Card>
  <Card title="Extensible" icon="puzzle-piece">
    A first-class addon system lets you add search, image rendering, clipboard access, web links, ligatures, and more without bloating the core.
  </Card>
  <Card title="Zero dependencies" icon="feather">
    The core library ships with no production dependencies. Add only what you need via optional addons.
  </Card>
  <Card title="Accessible" icon="universal-access">
    Screen reader mode, minimum contrast ratio enforcement, and ARIA live region support for NVDA and VoiceOver users.
  </Card>
</CardGroup>

## Getting started

<Steps>
  <Step title="Install the package">
    ```bash
    npm install @xterm/xterm
    ```
  </Step>
  <Step title="Create a terminal">
    ```typescript
    import { Terminal } from '@xterm/xterm';
    import '@xterm/xterm/css/xterm.css';

    const term = new Terminal();
    term.open(document.getElementById('terminal'));
    term.write('Hello from \x1B[1;3;31mxterm.js\x1B[0m $ ');
    ```
  </Step>
  <Step title="Connect to a process">
    ```typescript
    // Client-side: hook xterm.js to a WebSocket
    const socket = new WebSocket('ws://localhost:3000');
    socket.addEventListener('message', e => term.write(e.data));
    term.onData(data => socket.send(data));
    ```
  </Step>
  <Step title="Explore addons">
    Extend functionality with official addons:

    ```bash
    npm install @xterm/addon-fit @xterm/addon-webgl
    ```

    ```typescript
    import { FitAddon } from '@xterm/addon-fit';
    import { WebglAddon } from '@xterm/addon-webgl';

    const fitAddon = new FitAddon();
    term.loadAddon(fitAddon);
    term.loadAddon(new WebglAddon());
    fitAddon.fit();
    ```
  </Step>
</Steps>
