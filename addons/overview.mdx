Addons are modular packages that extend xterm.js with additional capabilities. Each addon is distributed as a separate npm package so you only pay for what you use.

## The addon system

Every addon implements the `ITerminalAddon` interface from `@xterm/xterm`. Loading an addon is always the same two-step pattern: install the package, then call `terminal.loadAddon()`.

```typescript
import { Terminal } from '@xterm/xterm';
import { SomeAddon } from '@xterm/addon-some';

const terminal = new Terminal();
terminal.open(containerElement);

const addon = new SomeAddon();
terminal.loadAddon(addon);
```

### ITerminalAddon interface

The interface is minimal by design:

```typescript
interface ITerminalAddon {
  activate(terminal: Terminal): void;
  dispose(): void;
}
```

`activate` is called automatically by `terminal.loadAddon()`. `dispose` is called when `terminal.dispose()` is called, or when you call `addon.dispose()` directly to unload the addon.

### Building your own addon

Anyone can build an addon. Implement `ITerminalAddon`, publish to npm, and consumers load it the same way as an official addon:

```typescript
import { Terminal, ITerminalAddon } from '@xterm/xterm';

export class MyAddon implements ITerminalAddon {
  private _terminal: Terminal | undefined;

  activate(terminal: Terminal): void {
    this._terminal = terminal;
    // set up event listeners, write data, etc.
  }

  dispose(): void {
    // clean up resources
  }
}
```
